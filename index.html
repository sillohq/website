The Modern Python Framework for Serious Builders

Sillo is a production-ready async Python web framework built for speed. Ship APIs, full-stack applications, real-time systems, and business-critical backends 10x faster with type-safe code, built-in authentication, ORM integration, caching, WebSockets, and queuing.

Unlike older frameworks, Sillo is async-first from the ground up. No callbacks, no complexity—just Python async/await powering your apps with high concurrency and minimal overhead.

Everything Built-In, Nothing Extra

🚀 Async-First Architecture

Built on ASGI with native async/await. Handle thousands of concurrent requests with minimal resources. No threads, no complexity—just Python async doing what it does best.

🔐 Security by Default

JWT authentication, bcrypt/argon2 password hashing, CSRF protection, security headers, and rate limiting included. Your app is secure before you write a line of code.

📦 Database Everything

Tortoise ORM for models, migrations, relationships. Query builder, pagination, transactions. PostgreSQL, MySQL, SQLite—all supported out of the box.

⚡ Real-Time Ready

WebSocket support with channels, groups, and broadcasting. Build chat apps, live notifications, collaborative tools without extra middleware.

🎯 Type-Safe by Design

Pydantic validation on every request. IDE autocomplete, runtime validation, automatic docs. Write less, catch bugs earlier.

🔄 Background Jobs & Caching

Redis-backed job queuing, task scheduling, and caching with fallback in-memory backend. Process long-running tasks without blocking.

Start Building in Seconds

Install Sillo and create your first API endpoint:

pip install sillo-framework

Then write your first route:

from sillo import silloApp
from sillo.core.http import Request, Response

app = silloApp()

@app.get("/projects/{project_id:int}")
async def get_project(req: Request, res: Response, project_id: int):
    # Automatic validation, automatic docs
    return res.json({"id": project_id, "name": "My Project"})

# Run: python -m sillo app:app
# Auto-reload enabled, full async support

What you get: Type validation, auto-generated OpenAPI docs, automatic reloading, async/await native. All in 7 lines.
